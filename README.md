# PMSS Scholarship App
# PMSSS – Paperless Scholarship Disbursement System

## 📌 About the Project

The **PMSSS Paperless Scholarship Disbursement System** is a digital platform developed to simplify and modernize the scholarship application and verification process under the Prime Minister's Special Scholarship Scheme (PMSSS).

The main objective of this project is to eliminate manual paperwork, reduce document verification time, improve transparency, and make scholarship disbursement more efficient through a secure digital platform.

The application is designed to connect students, SAG Officers, and administrators through a unified system.

## 🎯 Problem Statement

**SIH1728 – Development of a Paperless Scholarship Disbursement System for PMSSS**

The traditional scholarship process involves multiple verification stages and document handling, which can lead to delays, manual errors, duplicate applications, and difficulties in tracking application status.

Our proposed solution aims to digitize the entire process and introduce AI-powered assistance for faster and more reliable verification.

## 🚀 Key Features

### 👨‍🎓 Student Module
- Secure student authentication.
- Student profile and basic details management.
- UMIS ID-based student verification.
- DigiLocker-based document retrieval.
- Scholarship eligibility assessment.
- Scholarship application submission.
- Real-time application status tracking.

### 🏢 SAG Officer Module
- Dashboard for pending applications.
- Student document verification.
- AI-assisted application analysis.
- Application approval and rejection.
- Payment processing workflow.
- Application history and audit tracking.

### ⚙️ Admin Module
- Dashboard and application analytics.
- Scholarship scheme management.
- User and role management.
- Audit log monitoring.

## 🤖 Planned AI/ML Features

1. **AI Document Verification:** Extract and compare information from student documents using OCR.
2. **Duplicate Application Detection:** Identify potentially duplicate applications using UMIS ID and similarity matching.
3. **Eligibility Prediction:** Assess student eligibility based on scholarship rules.
4. **Fraud & Anomaly Detection:** Identify suspicious application patterns for further review.
5. **AI Application Summary:** Generate concise application summaries for SAG Officers.
6. **AI Scholarship Chatbot:** Assist students with scholarship-related queries.
